เกี่ยวกับระบบงานนี้ (About This System)

ULTRON Core System คือระบบบริหารจัดการข้อมูลและเอกสารระดับองค์กร ทำงานแบบ Local Sovereignty ประมวลผลและจัดเก็บบนเซิร์ฟเวอร์ภายในเครื่องอย่างสมบูรณ์แบบเพื่อความปลอดภัยสูงสุดของข้อมูล

ระบบนี้ทำอะไรได้บ้าง (Core Capabilities)

การจัดการสิทธิ์ตามบทบาท (RBAC)

ควบคุมการเข้าถึงเมนูและฟังก์ชันงานตามกลุ่มสิทธิ์ของผู้ใช้แต่ละคนอย่างเคร่งครัด

การจัดการเอกสารและการอนุมัติ

บันทึก จัดเก็บ ตรวจสอบ และอนุมัติเอกสารการทำงานในองค์กรอย่างเป็นระบบ

บันทึกประวัติการทำงาน (Audit Trail)

เก็บบันทึกทุกความเคลื่อนไหว การแก้ไข และการอนุมัติเพื่อความโปร่งใสและตรวจสอบย้อนหลังได้

ความปลอดภัยข้อมูลระดับองค์กร

เข้ารหัสข้อมูลขณะรับส่ง (AES-256) และเก็บรหัสผ่านด้วยการ Hash (Bcrypt) อย่างปลอดภัย

เลือกเมนูการทำงานที่ต้องการได้จากแถบเมนูด้านซ้ายตามสิทธิ์ที่ได้รับมอบหมาย
